**Installation instructions:**

Press CODE > Donwload .zip
Extract all 4 folders from inside the archive. Each folder contains media files for its respective AI.
Place all 4 folders into your "Stronghold Crusader Definitive Edition" directory into the "CustomMedia" folder.
The final location for all the extracted folders should be:
C:\Users\*your username*\AppData\LocalLow\Firefly Studios\Stronghold Crusader Definitive Edition\CustomMedia\

(Game files might be stored under a different path on your PC)
